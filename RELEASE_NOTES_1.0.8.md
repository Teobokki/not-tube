# NOT TUBE 1.0.8

The search bar is fixed.

- Clean rounded search box: no more square button corner or notch where the box meets the search button
- The search box never overlaps the Create / Check for updates buttons when the window is smaller
- "Search" placeholder, a clear (X) button, and a blue outline while you type
- Results match words in any order and ignore dashes, so "try on haul" finds "Try-on" videos
- On the results page, results update as you type (with a short pause, so typing stays smooth)
- Pressing Enter again on the same search no longer reloads the page; an empty search does nothing
- Esc clears the box (or leaves it) instead of jumping back to Home; Ctrl+A and Ctrl+Backspace work
- Clicking outside the search box gives the keyboard shortcuts (Space, F, M) back to the player
- Portable version is now a single .exe (no zip)

Your videos, thumbnails and the 1.0.7 frame fixes are unchanged.
